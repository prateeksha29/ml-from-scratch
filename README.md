# ML From Scratch

Implementing machine learning algorithms from scratch using NumPy for deeper understanding.

## Notebooks

| Notebook | Topics Covered |
|----------|---------------|
| [Optimizer Assignment](notebooks/optimizer_assignment.ipynb) | Gradient Descent, SGD+Momentum, RMSProp, Adam, AdamW |

## Purpose

This repo is a collection of hands-on implementation notebooks for revising core ML concepts. Each notebook focuses on building algorithms from scratch — no PyTorch/TensorFlow — to solidify understanding of the math and mechanics behind them.
